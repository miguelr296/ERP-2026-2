# /iniciar

1. Leer `README.md`, `docs/contexto.md`, `docs/decisiones.md` y `BITACORA.md`.
2. Confirmar con el usuario el área, alcance y tiempo disponible; revisar el estado de trabajo y PR antes de abrir otra tarea.
3. Consultar la fuente y el guion del área: `docs/pantallas/comercial.md` (Sesión 06) o `docs/pantallas/logistica.md` (Sesión 10). Bartolito ERP aporta la referencia visual; el contexto es una mueblería retail con varias sedes.
4. Trabajar solo con HTML, CSS y JavaScript; mantener el código simple y limpio.
5. No asumir avances ni registrar trabajo sin evidencia. Respetar el alcance autorizado.
