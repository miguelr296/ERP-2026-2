# Glosario

[Índice](../README.md)

| Término | Uso en esta entrega |
|---|---|
| Maestro | Registro compartido de cliente, producto, lista o promoción; su alta/cambio se revisa antes de publicar |
| Lista vigente | Lista aprobada y activa para canal/segmento, dentro de fechas inclusivas |
| Punto básico (bps) | Centésima de punto porcentual: 500 bps = 5 %; evita porcentajes monetarios ambiguos en los parámetros |
| Copia de condiciones | Valores conservados al crear la cotización y trasladados al pedido; no se sustituyen al consultar el catálogo |
| Excepción | Descuento superior al límite del Asesor, pendiente de revisión de otra persona de Jefatura |
| Aprobación comercial | Autorización del pedido tras sus controles; no acredita cobro ni salida física |
| Contrato de consulta | Función pública que solicita una respuesta al módulo propietario sin modificar sus registros |
| Disponibilidad | Cantidad informada por Inventarios; consultarla no crea una reserva |
| Exposición de crédito | Importe informado por Finanzas que consume el límite del cliente; no lo edita Comercial |
| Atención parcial | Cantidad entregada menor que la pedida, según documentos informados por Despachos |
| Solicitud de devolución | Documento comercial que pide autorización y sigue recepción, nota de crédito y ajuste de las áreas responsables |
| Correlativo local | Número asignado dentro del almacenamiento de este navegador; no es un correlativo tributario compartido |
