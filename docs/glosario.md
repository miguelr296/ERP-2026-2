# Glosario del flujo

[Índice](../README.md)

| Término | Significado |
|---|---|
| Sprint | Semana de trabajo con un área y un objetivo acordado |
| Núcleo | Recorrido mínimo comprometido para esa semana |
| API | Entrada del sistema que recibe peticiones de las pantallas |
| PR | Propuesta de cambios revisada por otra persona antes de integrarse |
| CI | Comprobaciones automáticas de compilación y pruebas |
| Workflow | Archivo que define cuándo y cómo GitHub Actions ejecuta las comprobaciones |
| Runner | Máquina que ejecuta los pasos de un workflow; COM-020 usa Ubuntu 24.04 alojado por GitHub |
| TRX | Informe XML con los resultados de una ejecución de pruebas .NET |
| WIP | Cantidad de trabajo abierto al mismo tiempo |
| Contrato | Acuerdo sobre entradas, resultados y errores entre módulos |
| Adaptador simulado | Implementación sencilla que imita un servicio aún no disponible |
| Historial | Registro inmutable de quién cambió qué, cuándo y por qué |
| Cadena documental | Relaciones entre un documento, su origen y sus derivados |
| Migración | Cambio versionado de la estructura de la base de datos |
| Esquema | Agrupación de tablas dentro de una base de datos; cada módulo usa el suyo |
| Dominio | Capa con entidades y reglas que no dependen de la persistencia |
| Aplicación | Capa con casos de uso y puertos; depende del dominio |
| Infraestructura | Capa que implementa la persistencia y los servicios externos |
| Caso de uso | Operación del negocio que la API puede invocar |
| Puerto | Interfaz que define la aplicación y que la infraestructura implementa |
| SDK | Herramientas para compilar y ejecutar el proyecto |
| CRM | Gestión de clientes y oportunidades comerciales |
| Catálogo comercial | Datos de los productos que se ofrecen para cotizar |
| Lista de precios | Precios de productos aplicables a un canal y tipo de cliente durante una vigencia |
| Tipo de cliente | Clasificación usada para consultar la lista de precios aplicable |
| OV | Orden de venta |
| TO-BE | Descripción del proceso de negocio propuesto |
| EF Core | Herramienta de acceso a datos para .NET |
