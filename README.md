# ERP FAMIHOGAR

Proyecto para desarrollar el área Comercial del ERP de FAMIHOGAR SAC usando únicamente HTML, CSS y JavaScript, con código simple y limpio. La referencia funcional es `docs/fuentes/Documento_TO_BE_FAMIHOGAR.pdf`.

## Cómo leer este repositorio

1. Lee `docs/contexto.md` para conocer el propósito y punto de partida.
2. Lee `docs/decisiones.md` para conocer los acuerdos vigentes.
3. Lee `BITACORA.md` para consultar el trabajo comprobado.
4. Consulta el PDF antes de definir reglas o recorridos comerciales.
5. Las pantallas iniciales son login y Aplicaciones, en `src/Erp.Api/wwwroot/index.html`, con sus recursos CSS y JavaScript.

## Flujo

- Inicio de sesión: `docs/comandos/iniciar.md` (`.opencode/command/iniciar.md`).
- Cierre: `docs/comandos/cierre.md` (`.opencode/command/cierre.md`).
